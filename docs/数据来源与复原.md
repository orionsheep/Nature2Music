# 训练数据来源与复原指南

本文档记录 Nature2Music 识别模型（Fun-ASR + Qwen3-0.6B LoRA）训练数据的完整来路。
本地训练数据已在交付后清理，按本文档操作可完整复原。

## 结论先行

**训练数据 100% 来自公开数据集 ESC-50，没有使用任何其他数据源。**

`metadata.csv`（仓库根目录）就是训练清单本身：600 行，每行对应一个训练切片，
其中 `recording_id` 与 ESC-50 原始文件名一一对应（如 `100032` ↔ `1-100032-A-0.wav`），
凭此文件即可精确复原训练集，无需任何猜测。

## 数据集信息

| 项目 | 内容 |
|---|---|
| 名称 | ESC-50（Dataset for Environmental Sound Classification） |
| 作者 | Karol J. Piczak |
| 仓库 | https://github.com/karolpiczak/ESC-50 |
| 许可 | **CC-BY-NC-3.0**（署名-非商业使用；比赛/研究用途适用，商用需另行授权） |
| 规模 | 2000 条环境录音，50 类 × 40 条，每条 5 秒、44.1kHz 单声道 |

## 复原步骤

```bash
# 1. 下载 ESC-50（仓库自带全部音频，约 1.2GB）
git clone https://github.com/karolpiczak/ESC-50.git data/raw/esc50

# 2. 用仓库根目录的 metadata.csv 生成训练清单
#    --audio-root 指向 ESC-50 的 audio/ 目录
nature2music manifest-from-csv metadata.csv data/processed/manifest.jsonl \
  --audio-root data/raw/esc50

# 3. 按原始录音分组切分（同一录音的切片不跨 split，seed=42 保证可复现）
nature2music split-manifest \
  data/processed/manifest.jsonl \
  data/processed/manifest.split.jsonl \
  --validation-ratio 0.1 --test-ratio 0.1 --seed 42

# 4. 校验并导出 Fun-ASR 训练格式
nature2music validate-manifest data/processed/manifest.split.jsonl \
  --min-train-per-species 20

nature2music export-funasr \
  data/processed/manifest.split.jsonl \
  data/processed/funasr

# 5. 训练（见 README 第 3 节）
bash scripts/train_funasr_lora.sh external/Fun-ASR data/processed/funasr runs/funasr-bioacoustic
```

## 注意事项

- **许可边界**：ESC-50 是 CC-BY-NC（非商业）。本项目为比赛/研究用途，合规；
  若未来商业化，需替换为可商用数据（如 Xeno-canto 中 CC0/CC-BY 的录音）或取得授权。
- **README 第 2 节提到的 Xeno-canto / InsectSet459 是"建议的扩展数据源"，实际训练并未使用**，
  仅 ESC-50。后续要扩充类别（如更多鸟类、昆虫物种）时才需要引入它们。
- 训练产物（权重）已开源在魔搭，不必重新训练：
  https://modelscope.cn/models/OrionSheep/Nature2Music-FunASR-Bioacoustic
