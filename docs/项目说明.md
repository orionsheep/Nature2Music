# Nature2Music · 自然之声，成乐

## 项目说明文档

---

## 一、一句话介绍

上传一段大自然的声音——鸟叫、虫鸣、雨声、海浪——AI 先「听懂」它，再为它写一首可以下载的歌。

- **在线体验**：https://music.orionsheep.com
- **模型开源**：https://www.modelscope.cn/models/OrionSheep/Nature2Music-FunASR-Bioacoustic

## 二、为什么做这个项目（立意）

城市生活让人们离自然越来越远。我们想用 AI 搭一座桥：把一段真实的自然之声，变成一段可以反复聆听的音乐。

每一段鸟鸣都有它独特的节奏、音区和情绪——乌鸦的聒噪是短促的断奏，海浪是缓慢的呼吸，夏夜的蟋蟀是稳定的高频脉冲。人类作曲家能听出这些并写成曲子，**我们要让 AI 也能**。

这不仅是一个好玩的工具，也是一次「AI For Good」的尝试：让更多人以新的方式感知自然、珍视自然——听见，才会在意。

## 三、产品功能

1. **上传 / 实时录音**：支持上传音频（wav/mp3/flac/ogg/m4a）或直接在网页里录制环境声（最长 30 秒），内置 15 类示例音频可一键体验
2. **AI 识别**：自训练生物声学模型输出结构化识别结果——声源物种（中/英文学名）、鸣叫类型、声学特征（节奏 BPM、主频、频谱质心、响度动态）
3. **可理解的中间层**：页面把「AI 如何理解这段声音」完整展示给用户，包括源声音波形和自动生成的创作说明（chain-of-thought），用户可编辑后再生成
4. **谱写成乐**：识别结果被翻译成音乐语言（物种→演奏手势映射、BPM→速度、主频→音区、频谱质心→明亮度、响度→力度），驱动音乐生成模型产出 2–30 秒乐曲
5. **试听与下载**：在线播放、一键下载 WAV、历史记录回溯

## 四、技术架构

```
自然声音 (wav)
   │
   ▼
┌─────────────────────────────────────┐
│ ① 生物声学识别（自训练，已开源）        │
│   Fun-ASR-Nano-2512 + Qwen3-0.6B    │
│   LoRA 微调（r=16, alpha=32）        │
│   输出：物种/学名/鸣叫类型 JSON        │
└─────────────────────────────────────┘
   │
   ▼
┌─────────────────────────────────────┐
│ ② 声学特征提取                       │
│   librosa：RMS / 频谱质心 / 主频 / BPM │
└─────────────────────────────────────┘
   │
   ▼
┌─────────────────────────────────────┐
│ ③ 语义→音乐语言翻译层（自研）          │
│   15 类声源 → 演奏手势映射表           │
│   声学特征 → 速度/音区/明亮度/力度      │
│   组合成 Lyria 生成提示词              │
└─────────────────────────────────────┘
   │
   ▼
┌─────────────────────────────────────┐
│ ④ 音乐生成：Google Lyria 3 Pro       │
│   ffmpeg 后处理：裁剪/淡入淡出/响度归一 │
└─────────────────────────────────────┘
   │
   ▼
生成的音乐 (wav, 44.1kHz 立体声)
```

**前端**：原生 HTML/CSS/JS，森林四时场景视频背景（清晨/中午/黄昏/午夜）、液态玻璃拟态卡片、源声音波形可视化、录音实时电平。

**部署**：阿里云 4C8G 云服务器（CPU 推理）+ nginx + HTTPS；识别模型本地推理保护隐私，音乐生成走云端 API。

## 五、核心自研点

1. **生物声学识别模型（已在魔搭开源）**
   - 基座：Fun-ASR-Nano-2512（音频编码器 SenseVoiceEncoderSmall + Qwen3-0.6B LLM）
   - 微调：冻结编码器与 LLM 主干，仅训练 LoRA（q_proj/v_proj）+ audio adaptor + CTC decoder，差异权重仅 149 个 key（约 370MB）
   - 数据：15 类自然声源（乌鸦/公鸡/母鸡/鸟鸣/猫/狗/羊/蛙/昆虫/蟋蟀/雨/雷雨/海浪/风/篝火），按录音组切分防止泄漏，训练 30 epoch 取验证集最优
   - 输出为严格结构化 JSON，可被下游程序稳定消费

2. **「声学特征→音乐语言」翻译层**
   - 不是简单把物种名丢给生成模型，而是把**这段具体声音**的节奏、音区、明亮度、力度翻译成作曲指令，保证生成音乐与源声音的相关性

3. **全链路独立完成**：数据清洗 → 模型训练 → 提示词工程 → 前端设计 → 云端部署 → 开源发布

## 六、效果示例

输入：5 秒乌鸦叫声 → 识别：`crow / Corvus / 乌鸦 / song`（BPM≈60，主频 32Hz，质心 2349Hz）→ 生成：以短促拨弦断奏和重复双音动机为主旨的 10 秒氛围乐曲（测试样例音频与完整识别报告已随上架材料提交）

## 七、硬件与成本说明

- **训练**：LoRA 微调在 NVIDIA GPU 上完成（Apple Silicon 无法承担该训练）
- **推理**：识别模型 CPU 可跑（4 核单次约 2 分钟，峰值内存 6.6GB），普通 4C8G VPS 即可承载全站服务
- **生成成本**：Lyria 3 Pro 按次计费（约 $0.08/次）

## 八、已知限制与后续方向

- 当前识别覆盖 15 类声源；`confidence`/`background` 字段为占位输出，后续版本将接入真实置信度与多声源混合识别
- 音乐生成时长上限 30 秒，后续计划支持段落化长曲生成
- 计划开放「声景地图」：用户上传的声音汇聚成一张可聆听的自然地图

## 九、开源与合规

- 识别模型以 Apache-2.0 在魔搭社区开源（与基座模型 Fun-ASR-Nano-2512、Qwen3-0.6B 许可兼容）
- 训练音频来自公开声学研究数据集（ESC-50、InsectSet459 等）的合规使用
- 生成音乐由 Lyria 3 Pro 产出，不克隆任何受版权保护的具体录音
