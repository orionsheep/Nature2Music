      能力边界说明

      Nature2Music 的声学生物识别模型在 ESC-50 数据集的 15 个类别上微调，只对这些声音可靠：

      cat 猫叫chirping_birds 鸟鸣crickets 蟋蟀 crow 乌鸦dog 狗吠frog 蛙鸣 hen 母鸡insects 昆虫rain 雨声 rooster 公鸡sea_waves 海浪sheep 羊叫 thunderstorm 雷雨wind 风声crackling_fire 篝火

      上传范围外的声音（如人声、乐器、城市噪声）可能被误识别为相近类别。模型按 5 秒样本训练，建议上传 3–30 秒的片段：过短识别不准，过长无额外收益。

      音乐由 Google Lyria 3 云端生成，输出为 44.1kHz 立体声 WAV，每次生成结果不同。声音识别与特征提取全部在本机完成，上传的音频不会离开这台电脑；仅文字创作描述（prompt）会发送给 Google API 用于作曲。
